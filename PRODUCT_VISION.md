# Viziunea produsului

Produsul este o platformă web profesională pentru formarea antrenorului-pedagog
care lucrează cu grupa comună 2015–2016, aproximativ 10–11 ani. Principiul
canonic este: **antrenorul trebuie format mai întâi ca pedagog și apoi ca
antrenor**.

Platforma unește studiul aprofundat cu utilizarea rapidă pe teren. Nu este o
enciclopedie liniară și nici o colecție de exerciții. Fiecare soluție leagă
problema observată de informația copilului, decizie, comportament, mesaj,
fundamentare, adaptare și transfer în joc.

Livrabilul principal este site-ul static Astro/TypeScript/MDX, accesibil și
utilizabil offline unde este posibil. PDF-urile pe capitol, fișele de exercițiu
și ședință, cadrele statice și pachetele editabile sunt derivate secundare.

Prima versiune produce exclusiv conținut 10–11 ani. Extinderea 4–18 ani este
pregătită prin metadate, fără curricule sau pagini pentru alte vârste.
