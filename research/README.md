# Structura cercetării

- `questions.json`: întrebări canonice;
- `search-logs.jsonl`: căutări append-only;
- `sources.json`, `claims.json`, `citations.json`: lanțul probator;
- `source-notes/`: note proprii;
- `source-snapshots/`: numai copii permise;
- `restricted-source-metadata/`: metadate fără opera protejată;
- `version-history/`: diferențe între versiuni;
- `evidence-matrices/`: sinteze pe întrebări;
- `review-queues/`: reverificări și drepturi;
- `audits/`: audituri factuale;
- `archive-manifests.json`: inventarul fișierelor permise.

Fixture-urile sunt exclusiv în `tests/fixtures/research/`.
