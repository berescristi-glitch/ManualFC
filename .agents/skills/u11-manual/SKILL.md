# U11 Manual Skill

Before work:

1. Read the root `AGENTS.md`.
2. Read `CODEX.md` and the relevant documents in `docs/`.
3. Read the task, its dependencies, and its ExecPlan.

For content tasks:

- Treat children born in 2015 and 2016 as one combined 10–11 age category.
- Explain both the instruction to the child and the rationale behind it.
- Separate perception, decision, execution, and result.
- Use evidence and declare uncertainty.
- Produce publishable Romanian, then run a separate editorial review.

For exercise and session tasks:

- Validate against the repository schemas.
- Include dimensions and their rationale.
- Include diagrams and dynamic representations where applicable.
- Verify realistic setup, active time, safety, progressions and match transfer.

For review tasks:

- Do not rubber-stamp completeness.
- Report concrete evidence, severity and required repair tasks.
