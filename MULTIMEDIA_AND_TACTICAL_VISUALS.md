# Multimedia și vizualuri tactice

Diagramele sunt instrumente de explicație. Varianta statică arată terenul la
scară, dimensiuni, porți, zone, conuri, jucători, minge, trasee, direcții,
spații, antrenor, legendă și margini de siguranță.

Interactivitatea poate include Play, Pause, Restart, pași, timeline, viteză,
straturi, faze numerotate, evidențiere, pase, presiune și alternative. Sursa
canonică este SVG + TypeScript + date structurate + storyboard + timeline
determinist. Din ea se generează cadre PDF și, opțional, export video scurt;
video nu este niciodată unica explicație.

Fiecare vizual are text alternativ, explicație textuală, tastatură, focus,
mișcare redusă, contrast, coduri care nu depind numai de culoare și print
alb-negru. Sunt prevăzute variante pentru antrenor, copil, print și animație.
