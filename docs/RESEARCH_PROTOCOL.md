# Protocol de cercetare și citare

## 1. Întrebări de cercetare

Fiecare capitol pornește de la întrebări precise. Exemple:

- Ce capacități cognitive sunt relevante pentru decizia tactică la 10–11 ani?
- Ce efect au jocurile reduse asupra numărului de acțiuni și decizii?
- Ce forme de feedback susțin autonomia și încrederea?
- Ce recomandă documentele oficiale privind formatul și siguranța U11?

Nu căuta „cea mai bună metodologie” ca formulă universală.

## 2. Surse prioritare

1. FIFA, UEFA, FRF și alte federații.
2. Regulamente și ghiduri oficiale în versiunea curentă.
3. Revizuiri sistematice și meta-analize.
4. Studii primare relevante.
5. Cărți academice și ghiduri profesionale.
6. Practici publice ale academiilor, marcate ca practici, nu dovezi.

## 3. Evaluarea sursei

Înregistrează:

- autoritate;
- relevanță pentru vârstă;
- anul;
- designul studiului;
- dimensiunea și caracteristicile eșantionului;
- limite;
- aplicabilitate la contextul de antrenament.

## 4. Registrul surselor

Câmpuri minime:

- `source_id`;
- titlu;
- autor/organizație;
- an;
- URL/DOI;
- data accesării;
- tip;
- rezumat;
- afirmații susținute;
- limitări;
- licență, când este relevant;
- locații de utilizare.

## 5. Registrul afirmațiilor

Nicio afirmație factuală importantă nu rămâne fără:

- identificator;
- formulare;
- sursă;
- tip de dovadă;
- nivel de încredere;
- context și limite;
- capitole de utilizare.

## 6. Sinteza

Textul trebuie să arate diferența dintre:

- ce este bine susținut;
- ce este recomandat de o federație;
- ce este o practică răspândită;
- ce este o alegere metodologică a manualului;
- ce rămâne incert.

## 7. Sursele vizuale

Folosește preferențial diagrame și ilustrații originale. Pentru orice resursă externă păstrează autorul, licența și atribuirea. Nu include imagini cu drepturi neclare în distribuția finală.

## 8. Audit

Un auditor separat trebuie să verifice selectiv cel puțin:

- toate afirmațiile de siguranță și dezvoltare;
- regulamentele și dimensiunile oficiale;
- afirmațiile despre eficiența unei metode;
- citările cu impact asupra recomandărilor.
