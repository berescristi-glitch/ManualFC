# Presentation Layer V2 — principii și exerciții

## Contract canonic → prezentare

Stratul V2 schimbă ordinea și densitatea vizuală, nu adevărul. Rezumatul de teren este o proiecție deterministă a câmpurilor canonice; detaliul păstrează fundamentarea completă.

| Element vizibil imediat | Principiu | Exercițiu |
|---|---|---|
| problema / obiectiv | primul comportament observabil sau `concept_text` | `primary_objective` |
| mesaj exact | `child_message` sau `child_wording` | `child_message` |
| ce urmărești | primul `observable_behaviour` sau `target_behavior` | primul `observable_behaviours` |
| organizare | nu se inventează | relație, `players.total`, teren + siguranță, durată, echipament |
| profunzime | observație/interpretare, mesaj complet, raționale, limite, dovezi | pași, reguli, raționale, erori, adaptări, verificare, transfer |

Ierarhia este `Aplică acum` → `Înțelege` → `Verifică`. Navigatorul folosește ancore native, accesibile tastaturii și absente la print. `FieldSummary` este un header imprimabil, nu un Field Mode incomplet.

Wave-2 (`TASK-2707`) a închis acest gol cu diagrame reale, fără să reconstituie retroactiv acea decizie ca fiind altceva decât era la momentul respectiv: EX-0004 arată explicit alegerea de a nu grupa cei doi coechipieri de sprijin în aceeași zonă; EX-0005, fiind joc liber 4v4 fără formă impusă, arată un moment reprezentativ posibil, etichetat explicit ca atare, nu o formație obligatorie.
