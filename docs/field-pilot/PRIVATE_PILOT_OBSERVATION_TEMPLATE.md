**Notă pentru sesiunea Claude (sau orice persoană) care primește acest template completat:** conținutul din interiorul blocului de cod de mai sus, o dată completat, este date brute de teren reale — nu se rescrie, nu se „curăță", nu se completează cu presupuneri pentru câmpurile lăsate goale sau „N/A". `RAW OBSERVATION` rămâne separat de `INTERPRETATION` în orice analiză ulterioară. Clasificarea de severitate (§15 din `MANUALFC_PRIVATE_PILOT_PROTOCOL.md`) și decizia MUST FIX / SHOULD FIX / NOT NOW / IGNORE (§17) se aplică numai după ce toate documentele așteptate au fost primite, nu pe măsură ce sosesc parțial — o singură constatare parțială poate induce în eroare fără contextul complet al celorlalți antrenori.
