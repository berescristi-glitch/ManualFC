# Fișă de teren CH-0204 — Protejarea centrului

## Problema

Primul apărător atacă frontal ori se retrage pasiv; colegul nu acoperă drumul către poartă, iar adversarul pătrunde central.

## Organizare

- 3v3 + doi portari, două porți centrale;
- punct de pornire: 30 × 22 m;
- minimum 2 m spațiu liber în spatele porților;
- porți fixate, mingi de rezervă în afara alergării;
- joc normal, fără coridor central ori comandă de orientare.

Dimensiunea este ipoteză ManualFC. Oferă un drum direct recognoscibil și spațiu lateral real. Reglează o singură dimensiune cu 2–3 m.

## Mesajul primului apărător

„Poarta e în spatele tău? Încetinește-l și arată-i drumul mai lung.”

## Mesajul celui care acoperă

„Dacă trece de colegul tău, ești pe drumul spre poartă?”

## Trei oportunități

| Oportunitate | Drum direct existent | Primul: încetinește/orientează | Al doilea: acoperă | Echilibru după mutarea mingii | Rezultat | Ajutor |
|---|---|---|---|---|---|---|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |

## Reglaj

- duel accidental, fără timp de frânare: +2–3 m la lungime;
- purtător fără presiune: −2–3 m la o singură dimensiune;
- apărători retrași pasiv: repornire mai aproape ori cinci secunde temporar pentru finalizare;
- dublaj orb: schimbă unghiul repornirii și întreabă cine protejează poarta;
- comportament doar după comandă: trei oportunități fără intervenție verbală.

## Siguranță

Oprește pentru poartă instabilă, coliziune sau suprafață periculoasă. Portarul are spațiu de aterizare, iar următorul grup nu așteaptă în spatele porții.

## Transfer

Joacă liber, apoi caută aceeași prioritate într-un alt loc. Marchează `autonom`, `după întrebare`, `după indicație` sau `oportunitate absentă`. Nu cere aceeași poziție.

## Test anti-bloc

Mută mingea pe cealaltă parte. Dacă apărătorii rămân în locul marcat și nu refac relația minge–poartă–adversar, au memorat forma, nu prioritatea.
