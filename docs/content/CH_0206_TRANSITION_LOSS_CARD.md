# Fișă de teren CH-0206 — Tranziția la pierderea mingii

## Problema

După pierderea mingii, copiii fie ignoră mingea, fie aleargă toți spre ea, lăsând drumul spre propria poartă neprotejat.

## Organizare

- 5v5 + portari, aproximativ 30 × 20 m, reguli normale de joc;
- variantă efectiv mic: 3v3 + portari, aproximativ 20 × 15 m;
- limitează atingerile la 2–3 pentru linia ofensivă, pentru a crește frecvența pierderilor fără reguli artificiale despre timp de recuperare;
- nu opri jocul la fiecare pierdere; observă din exterior primele momente, fără intervenție verbală.

Dimensiunile sunt ipoteze ManualFC, nu normă oficială. Reglează o singură variabilă odată.

## Mesajul

„Ai pierdut mingea. Cine e aproape, încetinește. Restul, închideți drumul spre poartă.”

## Trei momente de pierdere

| Moment | Cel mai aproape a ales influență/întârziere controlată | Centrul a rămas protejat | Restul s-a orientat spre poartă, nu spre minge | Reacție fără comandă verbală | Rezultat |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

## Reglaj

- toată echipa aleargă spre minge: oprește, arată spațiul gol din spate, reia din exact același loc;
- nimeni nu reacționează: simplifică temporar la 3v3 + portari pe spațiu mai mic, apoi revino la formatul mai mare;
- copil mai puțin experimentat: oferă un reper vizual (con) pentru „zona de protejat”, apoi elimină-l treptat;
- copil avansat: adaugă un adversar suplimentar aproape de locul pierderii, fără să schimbi mesajul de bază.

## Ce nu faci

Nu impune un cronometru copiilor („aveți 5 secunde”) — nu există prag de secunde validat științific pentru recuperarea mingii, la nicio vârstă. Nu preda presingul în bloc ca sistem cu roluri fixe; rămâne `PRACTICE_ONLY`, amânat pentru o etapă ulterioară.

## Siguranță și rotație

Oprește pentru aglomerare necontrolată în jurul mingii sau contact riscant. Perechea/grupul în așteptare stă în lateral și intră doar la semnal.

## Transfer

Verifică în joc liber 5v5 sau 7v7. Notează cine a influențat, cine a protejat centrul și cât de repede a apărut o formă recognoscibilă. Reușita repetată pe spațiu redus nu demonstrează transfer direct în meci complet.

## Test anti-tipar

Provoacă pierderea în zone diferite ale terenului (lateral, central, aproape de propria poartă). Dacă răspunsul copiilor rămâne identic indiferent de zonă, au memorat o mișcare, nu au citit situația.
