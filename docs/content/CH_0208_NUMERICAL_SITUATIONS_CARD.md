# Fișă de teren CH-0208 — Superioritate, egalitate și inferioritate numerică

## Problema

Copiii cu avantaj numeric îl irosesc driblând direct în adversar; copiii în inferioritate se aruncă disperat la minge și lasă totul deschis.

## Organizare

- 3v2 continuu cu tranziție, aproximativ 30 × 20 m, două porți mici;
- dacă apărătorii recuperează sau mingea iese din joc, echipa care ataca devine echipa care apără, doi jucători noi intră ca atacanți, raportul 3v2 se păstrează;
- variantă efectiv mare: două terenuri simultan;
- pentru copii cu nivel tehnic mai scăzut: 2v1 în loc de 3v2, spațiu mai mare.

Dimensiunile sunt ipoteze ManualFC. Reglează o singură variabilă odată.

## Mesajul

„Sunteți mai mulți aici? Folosește-i pe amândoi. Sunteți mai puțini? Alege ce aperi primul.”

## Trei faze cu situație numerică

| Fază | Atacantul cu avantaj a implicat coechipierul | Driblarea directă a avut sens | Apărătorul a prioritizat, nu s-a aruncat | Schimbarea raportului a fost recunoscută | Rezultat |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

## Reglaj

- superioritatea nu produce nicio diferență vizibilă: redu spațiul apărătorilor sau adaugă temporar un al treilea apărător pentru contrast clar;
- copil cu nivel tehnic mai scăzut: simplifică la 2v1, spațiu mai mare pentru atacanți;
- copil avansat: adaugă un al doilea apărător care revine rapid, pentru a forța recunoașterea schimbării de la superioritate la egalitate.

## Ce nu faci

Nu recompensa doar golul marcat în superioritate sau doar recuperarea în inferioritate — notează decizia, nu doar rezultatul fazei. Nu cere copiilor să numere explicit adversarii cu voce tare; ei citesc situația global.

## Siguranță și rotație

Oprește pentru contact necontrolat la duelurile 1v1 din interiorul fazei 3v2. Grupul în așteptare stă în lateral și intră doar la semnal.

## Transfer

Verifică în joc liber 5v5 sau 7v7. Notează dacă superioritatea sau inferioritatea locală este recunoscută și folosită/gestionată, nu doar în exercițiul dedicat cu raport numeric fixat.

## Test anti-tipar

Provoacă situația numerică în zone diferite ale terenului (margine, careu, centru). Dacă răspunsul copiilor rămâne identic indiferent de zonă, au memorat o mișcare, nu au citit situația.
