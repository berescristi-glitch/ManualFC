# Fișă de teren CH-0202 — Spațiu și unghiuri

## Problema observată

Doi jucători fără minge sunt acoperiți de același adversar, iar purtătorul nu are o linie funcțională.

## Organizare

- 3v3, două porți mici, direcție clară și mingi de rezervă;
- punct de pornire: 28 × 22 m;
- minimum 2 m zonă de siguranță în spatele porților și distanță față de alte grupuri;
- porți fixate conform echipamentului;
- joc normal, fără benzi obligatorii, trasee sau număr impus de pase.

`28 × 22 m` nu este valoare oficială ori optimă. Oferă suficientă lățime inițială pentru două căi și păstrează adversarul relevant. Reglează 2–3 m într-o singură direcție.

## Mesajul copilului

„Mută-te până când adversarul nu vă mai poate acoperi pe amândoi.”

## Observație pe trei oportunități

| Oportunitate reală | Percepție: vede cine acoperă? | Decizie: schimbă relația? | Execuție: ajunge/orientează? | Rezultat și ajutor |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

Absența pasei nu este automat eșec. Notează dacă poziția a creat o linie ori spațiu pentru alt coleg.

## Reglaj cu o singură variabilă

- nicio linie nu rămâne vizibilă: +2–3 m la lățime;
- adversarul nu poate influența două opțiuni: −2–3 m la lățime sau lungime;
- copilul nu are timp să observe: două reporniri 3v2, apoi revenire la 3v3;
- apare poziția doar din comandă: antrenorul tace următoarele trei oportunități.

## Verificarea transferului

Scoate orice exagerare și joacă liber. Caută aceeași problemă în alt loc al terenului și o soluție adaptată, nu aceeași poziție. Marchează `autonom`, `după întrebare`, `după indicație` sau `oportunitate absentă`.

## Test anti-poziție

Dacă jucătorul rămâne în același loc când mingea și adversarul se mută, a învățat reperul, nu relația. Schimbă repornirea și verifică din nou.
