# Fișă de teren CH-0205 — Presiune și acoperire

## Problema

Doi apărători atacă aceeași minge sau niciunul nu influențează purtătorul; după depășire ori pasă, nu există răspuns.

## Organizare

- 2v2 + doi portari, două porți centrale;
- aproximativ 24 × 18 m;
- serii de 60–75 secunde; a treia pereche recuperează mingile și intră imediat;
- la efectiv mare, două terenuri, nu coadă;
- minimum 2 m în spatele porților; porți fixate și schimb în lateral.

Dimensiunea este ipoteză ManualFC. Reglează o singură variabilă cu 2–3 m.

## Mesajul

„Unul îl încetinește. Celălalt: dacă trece, poți fi tu următorul?”

## Trei oportunități

| Oportunitate | Primul influențează controlat | Acoperirea supraviețuiește depășirii | Rolurile se schimbă la pasă | Rezultat | Ajutor |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

## Reglaj

- faza se termină înaintea acoperirii: +2–3 m la lungime sau atacanți mai departe;
- al doilea stă pasiv foarte adânc: −2–3 m la lungime;
- ambii sar la minge: reașază acoperirea un pas și arată consecința pasei;
- ambii sunt pasivi: repornire cu 2 m mai aproape;
- complexitate excesivă: 2v1, al doilea apărător intră după prima pasă, apoi revenire la 2v2.

## Siguranță și rotație

Oprește pentru poartă instabilă, coliziune sau intrare necontrolată. Nu recompensa tacklingul. Perechea în așteptare stă în lateral și intră doar la semnal.

## Transfer

Joacă 3v3 sau 5v5 liber. Caută cine influențează, cine acoperă și dacă rolurile se schimbă la pasă. Marchează `autonom`, `după întrebare`, `după indicație` sau `oportunitate absentă`.

## Test anti-pereche

Schimbă partea și primul receptor. Dacă aceiași copii păstrează rolurile indiferent de minge, au memorat perechea, nu relația.
