# Fișă de teren CH-0207 — Tranziția la câștigarea mingii

## Problema

Copiii fie lovesc mingea înainte fără informație, fie o țin prea mult din prudență și pierd momentul în care drumul era liber.

## Organizare

- 4v4 + portari, aproximativ 25 × 18 m; antrenorul sau un jucător neutru pasează mingea echipei care primește;
- primele 2 secunde fără presiune excesivă, pentru a permite un prim contact real, apoi joc normal;
- variantă efectiv mare: două terenuri simultan de 3v3 + portari.

Dimensiunile sunt ipoteze ManualFC. Reglează o singură variabilă odată.

## Mesajul

„Ai câștigat mingea. Uită-te: ai loc să mergi înainte sau ai nevoie de un coleg aproape?”

## Trei momente de câștigare

| Moment | Primul control a rămas curat | A apărut o privire reală înainte de decizie | Alegerea s-a potrivit cu spațiul | Coleg apropiat a oferit opțiune reală | Rezultat |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

## Reglaj

- controlul se pierde constant: redu presiunea inițială sau mărește spațiul cu 2–3 m;
- toate reacțiile sunt identice indiferent de spațiu: adaugă un adversar care închide o singură opțiune, nu toate;
- copil mai puțin experimentat: elimină temporar presiunea imediată, apoi adaugă treptat un adversar la distanță tot mai mică;
- copil avansat: adaugă un al doilea adversar sau reduce spațiul, fără să schimbi mesajul de bază.

## Ce nu faci

Nu recompensa viteza reacției cu punct suplimentar — nu există dovadă că a ataca imediat este mai eficient la U11; eficiența contraatacului este documentată doar la nivel profesionist adult. Nu impune „păstrează mereu mingea în siguranță” ca regulă opusă.

## Siguranță și rotație

Oprește pentru presiune inițială necontrolată sau contact riscant la primul control. Perechea/grupul în așteptare stă în lateral și intră doar la semnal.

## Transfer

Verifică în joc liber 5v5 sau 7v7. Notează cât de des apare controlul curat, privirea reală și o decizie potrivită situației, nu doar rezultatul imediat al fazei.

## Test anti-tipar

Provoacă recuperarea mingii în zone diferite ale terenului și cu presiune inițială variabilă. Dacă răspunsul copiilor rămâne identic indiferent de situație, au memorat o mișcare, nu au citit-o.
