# Ghid pentru citarea exactă

Locatorul folosește pagina fizică PDF și, când diferă, pagina imprimată; secțiunea, paragraful, tabelul, figura, timestampul video sau articolul de regulament. Pentru web se păstrează titlul secțiunii, ancora, data accesării și snapshotul/hashul când este permis.

Citatul direct este scurt, marcat exact și păstrează locatorul. Se preferă parafrazarea fidelă. Versiunea documentului citat este obligatorie pentru surse actualizabile.

O pagină generală nu susține o afirmație precisă fără locatorul fragmentului relevant.
