# Politica drepturilor pentru surse vizuale

Fotografiile, pictogramele, ilustrațiile, capturile, graficele, diagramele adaptate, video, animațiile și logo-urile externe cer autor, deținător, sursă, licență, permisiune, atribuire, modificare, utilizare comercială și canalele permise: web, PDF, editabil.

`VISUAL_ASSET_SOURCE` fără licență și `visual_rights` este invalidă. Drepturile neclare blochează buildul public. Logo-urile nu sunt folosite decorativ.

Diagramele tactice create integral în proiect sunt marcate drept originale; sursele factuale ale datelor reprezentate rămân citate separat.
